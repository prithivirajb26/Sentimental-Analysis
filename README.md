# SentiSense — React Frontend

A clean React + Vite frontend for the Sentiment Analysis Flask backend.

## Setup

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Requirements

Make sure the Flask backend is running first:
```bash
py app.py   # in SentimentAnalysis_clean folder
```

## Build for Production

```bash
npm run build
```

## Tech Stack
- React 18 + Vite
- Plain CSS (no UI library)
- DM Serif Display + DM Sans fonts
